# ISO Temas 1–4 · Entrenador de Exámenes (Temario 26/27)

Aplicación web autocontenida adaptable a **ordenador, tablet y móvil** para preparar los Temas 1–4 de Introducción a los Sistemas Operativos (Temario 2026/2027).

## Qué incluye
- **8 exámenes oficiales (2022–2026)** · 268 preguntas verificadas (253 vigentes + 15 recortadas marcadas y saltables).
- **Diagnóstico pedagógico completo al fallar:** por qué tu opción es falsa, por qué la solución es cierta, **regla clave con ejemplo práctico**, **61 trazas visuales / Gantt paso a paso** y **12 esquemas SVG**.
- **Repaso de fallos y dudas (Blindaje 2/2)** persistente en navegador (`localStorage` + exportar/importar `.json` entre dispositivos).
- **4 Laboratorios infinitos** (Gantt CPU, Nodos-i UNIX con SVG dinámico, 6 Zonas de Disco, Permisos y Rutas) + **7 Problemas Clásicos (2018–2024)**.
- **40 Trampas Mortales** (con Modo Autotest) + **Formulario 26/27**.
